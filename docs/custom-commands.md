# 自定义命令

Native Agent 支持以 Markdown 文件定义可复用的提示词，通过 `/名称 参数` 调用。

- 项目目录：绑定的工作区根目录下 `.agents/commands/`，不向父目录查找。
- 用户目录：用户主目录下 `.rcode/commands/`，不受 `RCODE_DATA_DIR` 影响。
- 项目命令优先于同名用户命令；停用的项目命令也会遮蔽同名用户命令。
- 插件可通过 `commands/` 或 manifest 的 `commands` 字段提供命令，名称为 `/plugin:插件名:命令名`；关闭插件后不再加载。
- 子目录形成冒号命名空间，例如 `frontend/review.md` 对应 `/frontend:review`。
- 内置 `/compact`、`/c`、`/core:compact` 和 `/goal` 不允许被文件命令覆盖。

```markdown
---
description: 检查代码改动
argument-hint: [范围]
enabled: true
---
检查当前代码改动，重点关注正确性和回归。
检查范围：$ARGUMENTS
```

正文支持 `$ARGUMENTS` 和 `$1`、`$2` 等位置参数。单引号、双引号可将含空格的内容视为一个参数；反斜杠按字面保留，兼容 Windows 路径。正文没有参数占位符时，调用参数追加在正文后。参数内容不会被再次当成模板展开。

设置 → 命令可创建、编辑、删除、启停全局命令，并显示插件命令。新建文件统一写入 `~/.rcode/commands`。编辑器填写完整 Markdown，可包含上述 frontmatter。项目命令随项目维护；插件命令由插件维护。保存和删除校验文件修订值，外部修改后需重新加载，避免覆盖外部编辑。

斜杠菜单每次重新打开读取最新目录。命令正文仅在调用时进入本轮模型输入，不添加到常驻系统提示词。聊天显示原始调用，展开结果作为独立快照随会话文档持久化；后续重放、重试、分支对话使用当次快照，不重新读取历史命令文件。

首版执行字段为 `description`、`argument-hint`、`enabled`。其他 frontmatter 保留为元数据，不改变模型或工具权限；动态 shell 展开暂不支持，调用时明确报错。

发现阶段限制目录深度、文件数量和单文件 100 KB 大小。非法、空白或损坏的文件不会进入命令目录，日志记录原因。写入和启停只操作用户命令目录，并拒绝路径穿越和符号链接。
