# RCode 0.0.2-beta.1

本次更新重点改进终端 CLI 协作、Agent 执行可靠性、后台进程管理和远程会话恢复，并整合 Flutter 移动端工作。

## 新增与改进

- **终端程序状态**：支持 OSC 7501 协议。支持该协议的 CLI 可以上报执行中、等待批准、等待回答、完成和失败等状态；终端标签显示状态图标，悬停查看进度、说明和子任务。
- **后台命令**：管理和恢复后台进程，持久保存命令日志，并通过独立输出页查看结果。改进进程树退出、日志回收和永久删除会话时的清理。
- **运行中协作**：支持在步骤边界纠正 Agent，以及将消息排队到后续执行；保留排队消息和首次发送的重试身份，减少重复投递。
- **长任务与上下文**：完善 TODO 生命周期、目标完成核验、历史恢复和上下文压缩，改进工具调度、模型超时及流式中断后的恢复。
- **远程连接**：完善鉴权连接、自动重连、设备路由和无界面服务；按来源设备读取工具详情与子智能体内容，撤销旧连接后拒绝过期请求。
- **界面与资源**：补齐中英文状态与错误提示，修复侧栏置顶和分组初始化，改进 Windows 文件链接、缓存使用、壁纸资源回收和减少动态效果设置。

## 稳定性与安全

- 补齐 macOS 打包烟测使用的字体与图标许可文件，保留完整分发许可校验。

- 加强 MCP 连接健康反馈、工具命名与路由一致性，防止失败调用被自动重复执行。
- 改进插件配置并发写入、损坏配置处理、卸载路径和更新下载的信任边界。
- 修复持久化容器的内存安全问题，更新 TLS、ZIP、终端和 YAML 等依赖，并完善发行包架构、版本和许可文件校验。
- 修复 Windows 刷新率回退、AMD Vulkan 冷启动绘制及多处取消、注销和资源释放问题。

## 移动端

Android / iOS 客户端已迁移到 Flutter，共用远程会话、草稿、附件、队列、问题回答、公式和可视化能力；补充离线缓存、断线恢复、外接键盘导航、系统字号和手机/平板布局改进。

移动端设备验证范围和限制见 [Flutter 迁移与验证记录](https://github.com/chengliang4810/RCode/blob/v0.0.2-beta.1/docs/flutter-mobile-migration.md)。本次 GitHub Release 提供桌面及 Linux 服务端发行包；不包含 Android APK、iOS 安装包或 TestFlight 发布。

## English

RCode 0.0.2-beta.1 adds OSC 7501 terminal program status, persistent background-command logs, step-boundary steering and queued delivery, stronger TODO and goal-completion handling, and more reliable remote-session recovery.

It also improves MCP tool routing and connection health, plugin and update boundaries, cancellation and resource cleanup, localization, Windows file links, and rendering behavior. Dependency updates include terminal, TLS, ZIP and YAML libraries, with memory-safety fixes for persistent containers.

The Android and iOS clients now use Flutter, with expanded conversation, attachment, queue, math, visualization and offline-cache support. This release distributes Windows x64, macOS Intel / Apple silicon, and Linux x64 / ARM64 packages. Mobile installers and TestFlight builds are not included.

See the [full comparison](https://github.com/chengliang4810/RCode/compare/v0.0.1-beta...v0.0.2-beta.1) and the [mobile validation record](https://github.com/chengliang4810/RCode/blob/v0.0.2-beta.1/docs/flutter-mobile-migration.md) for details.
