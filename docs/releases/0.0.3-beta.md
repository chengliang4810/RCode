# RCode 0.0.3-beta

## 会话与编辑体验

- 思考文本在生成时实时预览，展开后可滚动查看完整内容；提问工具不再在工作记录中重复显示。
- 修复短对话中滚轮误触发“滚动到底部”按钮，以及窗口大小变化后按钮未及时隐藏的问题。
- 简化正文链接样式，改进悬浮提示；统一正文、侧栏、详情、菜单和浮层的字号与行高。
- 改进输入区附件的进入、移除和加载反馈，以及排队消息的操作反馈。
- 文件预览显示真实保存进度，保存失败时保留编辑内容。
- 后台进程入口统一放入会话详情，可继续查看进程状态与输出。

## 外观与终端

- 支持按工作区设置壁纸范围和局部磨砂表面。
- 改进界面元素的进入、退出和连续过渡，统一骨架加载反馈；滚动边缘渐隐按实际隐藏距离显示。
- 修复 Windows 键帽 Emoji 的字体回退和字体行高，改进中文输入取消时的选区处理。
- 终端保留组合字符，改进光标与字形定位；没有音频输出设备时跳过提示音播放。

## 性能与可靠性

- 侧栏只构建视口内的会话行，同时保留拖拽、焦点和其他交互需要的行。
- 长期低负载时回收界面元素池、键盘分派节点和图形缓存；释放已删除布局节点持有的测量上下文。
- Windows 按窗口的实际绘制需求调度帧，最小化时暂停绘制，并在空闲时释放可重建的图形资源。
- 减少会话快照导出时的重复文本分配，按并发需要管理运行日志缓存，并及时释放结束任务的句柄。
- 限制空闲原生运行时的保留数量，同时保留会话恢复能力。
- 合并读取仓库配置，保留远程解析回退；Windows 可执行文件嵌入版本信息。

本次发行提供 Windows x64、macOS Intel / Apple 芯片和 Linux x64 / ARM64 桌面或无界面服务包，不包含 Android / iOS 安装包。macOS 使用临时签名，尚未经过 Apple 公证。

## English

- Preview streaming thoughts live and retain the complete scrollable detail. Avoid duplicate question-tool entries in activity groups.
- Fix jump-to-bottom visibility for short conversations and viewport changes. Improve links, hover feedback, typography, attachment transitions, queued-message controls, and file-save progress while preserving edits after failures.
- Place background-process controls in session details. Add workspace wallpaper scopes and local frosted surfaces, refine transitions and loading feedback, and base scroll-edge fades on actual hidden content.
- Improve Windows emoji fallback, font metrics, and cancelled IME selections. Preserve terminal combining marks and improve cursor and glyph positioning. Skip notification sounds when no audio output device is available.
- Build visible sidebar rows while retaining active interactions. Reclaim underused UI pools, layout contexts, and graphics caches; schedule Windows frames on demand and suspend minimized windows.
- Reduce snapshot allocations, bound idle native runtime retention while preserving recovery, manage run-journal caches by concurrency, and release completed-task handles. Batch repository configuration reads and embed Windows executable version metadata.

This release provides Windows x64, macOS Intel / Apple silicon, and Linux x64 / ARM64 packages. Android and iOS installers are not included. macOS packages are ad-hoc signed and are not notarized by Apple.
