# RCode 0.0.2-beta.2

## 设置

- 设备与快捷键交换位置。
- Agent 能力按插件、技能、命令、个性化、MCP、子智能体、插件市场、模型设置排列。
- 本机端口与 API Key 自动保存，移除本机保存按钮；添加远程设备使用带加号的主要按钮。
- 保存或加载期间的设备操作按顺序处理，保留失败后的草稿与操作，避免切换设备后执行旧请求。

## 可靠性修复

- 远程连接断线后不再盲目重放创建工作树等写操作；保留明确只读和幂等操作的安全重试。
- 新附件使用完整上传身份，避免短 ID 碰撞覆盖或显示错误缩略图；上传提交可安全重试，历史附件仍可读取。
- 修复远端时钟偏快时，本地改名、归档和删除可能报告成功却未生效的问题。
- 修复文字增量更新丢失时长或排除标记，以及积压订阅阻塞同一连接其他请求回复的问题。
- 修复超时后晚到的移动端 WebSocket 连接泄漏。
- 修复 raw GPU 纹理缓存遗漏尺寸而复用错误纹理的问题。
- 修复 Linux 服务安装的可执行路径转义，以及服务凭据文件的权限与原子写入。
- 更新暂存目录按调用隔离，避免并发下载相互删除；保留已校验的历史缓存，避免删除正在使用的安装源。
- 打包直接使用本次 Cargo 构建报告的可执行文件，避免外部 target 目录配置下装入同版本旧程序。
- 更新 Tokio 和 ChaCha20 补丁版本，处理 Unix 文件描述符安全公告及旧 x86 CPU 的 SSE2 兼容问题。

新客户端的上传 ID 保持旧主机可接受的格式；未升级主机仍保留其原有短 ID 存储限制。历史短名称中已经丢失的完整身份或被覆盖的字节无法由本次更新恢复。

本次发行提供 Windows x64、macOS Intel / Apple 芯片和 Linux x64 / ARM64 桌面或无界面服务包，不包含 Android / iOS 安装包。macOS 使用临时签名，尚未经过 Apple 公证。

## English

- Reorder Settings: Devices before Shortcuts; agent capabilities now appear as Plugins, Skills, Commands, Personalization, MCP, Subagents, Plugin Marketplace, and Model Settings.
- Save local device settings automatically and use a primary Add Remote Device button. Preserve queued device operations and drafts across in-flight saves, loading failures, and retries.
- Stop replaying uncertain remote mutations, preserve complete attachment identities, make upload commits idempotent, and remove ambiguous thumbnail aliases.
- Preserve causal local registry edits after observing remote clocks, transcript metadata during text appends, and explicit null RPC stream values. Keep lagging subscriptions from blocking unrelated replies.
- Close late mobile WebSocket handshakes, distinguish raw texture dimensions, and install Linux services with correctly escaped paths and private, atomically written credentials.
- Isolate concurrent update stages and retain verified historical caches rather than deleting another installer's source. Package the executable reported by the current Cargo build instead of guessing a target directory.
- Update Tokio and ChaCha20 to compatible patch releases covering Unix file-descriptor safety and SSE2 compatibility on older x86 CPUs.

New upload identities remain acceptable to older hosts, which retain their original short-ID storage limitations. Previously lost attachment identities or overwritten bytes cannot be reconstructed by this update.

This release provides Windows x64, macOS Intel / Apple silicon, and Linux x64 / ARM64 packages. Android and iOS installers are not included. macOS packages are ad-hoc signed and are not notarized by Apple.
