## 验证与改善证据

- `rcode-visual-gpu` 新增极端尺寸边界和过期上传错误恢复测试。初轮 15 项中 14 项通过；`light_fades_out_toward_the_edges_unless_opaque` 在当前 Windows GPU 上返回全零 light 帧。将 4 个 GPU 文件临时替换为原始 HEAD、以完全相同的多 crate Cargo 参数重新构建后，该测试在原始 `shader.rs:835` 同样失败，确认属于本次修改之前已存在的问题；对照结束已恢复全部修改。
- GPU 原有纹理方向、反馈 buffer、lit scene、环境贴图和透明表面测试均在初轮通过，表明测试实际走了本机 GPU；没有测量或宣称帧率提升。
- 原有 room 测试新增实际 GPU texture handle 相等断言，检查连续帧确实复用同一 dummy；另加 `bloom_blur_bindings_preserve_glow_across_frames` 检查无 bloom 时圆盘外 alpha 为零、开启 bloom 后有光晕、跨帧结果一致，覆盖本次 bind 复用分支。
- 新增 bloom 回归已在本机 GPU 上通过；恢复本次全部源码后，过滤已确认的基线失败重新执行 GPU suite，结果 15 项通过、1 项基线失败被过滤。
- 新增 UI 回归：`background_preparation_keeps_unrelated_trees_and_prunes_removed_parsers` 验证删除后 parser 清除、无关 upsert 后同一 Arc tree 保留；`background_preparation_reuses_unchanged_rows_and_replaces_same_length_text` 继续验证同长度替换正确性。
- UI 初次相关回归 42 项通过、1 项新测试失败，暴露删除前置消息导致不变 entry 作为位置 upsert 传输的情况；随后修正为比较 parts 内容，保留该断言并新增同 entry 删除单个 part 的 parser 清理检查，等待重跑。
- 新增附件回归：`image_errors_are_bounded_without_evicting_active_loads`、`clipboard_bmp_rejects_dimensions_above_the_decode_limit`；新增 `client_initialization_failure_is_an_asset_error`；Windows `helper_process_timeout_terminates_and_reaps_the_child` 以 100 ms 截止验证 30 秒睡眠 helper 被终止。
- preview：`persisted_unicode_labels_do_not_panic_at_byte_limits`。主任务已完成 preview 全部 9 项测试，以及 UI asset_http、attachments、sound 和 background_preparation 共 43 项相关测试，全部通过。UI 其余 1785 项未运行，详见主复核记录。
- 资源次数改善为代码路径的确定性减少；未做系统帧率、全会话内存曲线、跨平台 UI 点击或 device-loss 注入测试。
