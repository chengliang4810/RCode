# 桌面窗口与工具栏控件规范

窗口控件属于产品的公共组件。新增页面和入口应复用公共规格；同一层级、同一排控件共享图标画布、按钮尺寸、间距、颜色和垂直中心，避免逐个页面调整数值。

## 两种控件层级

| 使用场景 | 图标画布 | 按钮区域 | 同组间距 | 默认图标颜色 |
| --- | --- | --- | --- | --- |
| 窗口标题栏：侧栏开关、前进/后退、新建、视图菜单、面板开关、自绘窗口按钮 | 16 × 16 | 28 × 28 | 4 | `theme.text_muted` |
| 面板内部工具栏：文件、浏览器、Diff、PR 详情 | 14 × 14 | 24 × 24 | 4 | `theme.text_muted` |

单位是 GPUI 逻辑像素；在 macOS 上对应 pt。不同语义组之间可以使用 8px 分隔。标签页的关闭入口、行内动作、正文装饰图标属于各自组件，不能以窗口工具栏的规格覆盖其布局。

公共尺寸和标题栏行构造函数位于 `crates/ui/src/chrome.rs`。`surface_chrome` 复用其中的紧凑工具栏规格；`Theme` 的标题栏尺寸也是该文件的别名。

## 对齐与图形

- 窗口标题栏高 38，顶部内边距为 4，内容中心线为 `(38 + 4) / 2 = 21`。聊天、设置上的窗口控件、PR 路由标题栏及自绘窗口按钮使用同一行构造函数。
- 统一按图标画布和中心线布局，同时检查 SVG 内部留白、笔画和可见边界。相同 `width`、`height` 不代表相同视觉尺寸。
- 自绘窗口图标使用随应用嵌入的 SVG，采用与标题栏图标一致的 24 单位坐标和 1.75 单位线宽，在 16px 画布内显示。不能依赖系统私用区字符或可选图标字体。
- 悬停、按下和选中可以使用强调色。关闭按钮悬停时使用红底白图标；默认态仍与相邻图标一致。
- 控件尺寸改变时，同时更新标题栏避让、侧栏菜单边界、面板展开预算和窄窗口布局。点击区域应排除窗口拖拽命中区域。
- 侧栏最小宽度也按标题栏预算推导：Windows 保持 242px，macOS 为 264pt，Linux 为可能出现三个左侧窗口按钮的布局预留 282px；默认宽度不能小于对应平台的最小值。

## 平台行为

### macOS

保留 AppKit 原生红黄绿按钮的尺寸、颜色和系统行为。应用控件按相同的垂直中心线布局，不重新绘制或缩放原生按钮。

当前平台设置按原生按钮框高 14pt 计算，将其顶部放在 14pt，使中心落在 21pt。初始位置由公共中心线推导，普通窗口左侧控件从 88pt 开始避让，原生全屏时从 12pt 开始；这些设置与标题栏控件共用定义。

原生按钮实际框高仍由 AppKit 决定。如果系统版本、窗口样式或缩放发生变化，必须在 macOS 实机检查原生按钮框与应用控件的中心；Windows 截图和几何单元测试不能替代该项验收。

### Windows

自绘按钮遵循标题栏规格，保留 `WindowControlArea` 原生命中处理，支持最小化、最大化/还原、关闭和系统支持的 Snap Layouts。精简 Windows 不需要额外安装图标字体。

### Linux

客户端装饰模式下，自绘按钮使用同一标题栏规格，并按桌面环境给出的左/右顺序布局；服务端装饰仍由窗口管理器绘制。该模式的显示效果需要 Linux 实机验收。

## 验证要求

修改公共规格或标题栏入口时，检查深浅主题、侧栏展开/收起、窄窗口、面板开合、设置页、最大化/还原；macOS 额外检查原生红黄绿按钮以及进入/退出原生全屏后的对齐。

可运行以下定向回归，覆盖标题栏预算、紧凑控件、图标资源和 PR/面板布局：

```powershell
cargo test --locked -p rcode-ui --lib titlebar -- --test-threads=1
cargo test --locked -p rcode-ui --lib chrome:: -- --test-threads=1
cargo test --locked -p rcode-ui --lib icons::tests:: -- --test-threads=1
```

原生视觉检查使用隔离数据的 fixture，保留同一窗口尺寸、相同状态的修改前后截图；同时核对可见图形和悬停按钮区域。页面自己的可滚动内容、表单控件和正文图标不应因标题栏规范改变而一起缩放。
